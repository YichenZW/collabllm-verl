**CollabLLM 复现结果汇总**

整理日期：2026-10-23（America/Chicago）。以下是 2026-10-13 完成并审计的实验结果；本次仅整理已有记录，没有新增训练、评测或付费 API 调用。

**完成范围是预算内的部分复现。** 我们完成了写作、代码、数学三个任务的 SFT 和 Offline DPO 全部预定训练轮次，以及 Base、Proactive Base、自训 SFT、自训 Offline DPO、作者公开适配器的评测。PPO 和 Online DPO 仅完成数学任务上的优化器诊断，没有完整训练或 Table 1 测试成绩。veRL 仅做源码分析，没有训练结果。

最终纳入汇总的 15 组评测共 **1,172 个模型—任务实例**，每组均完成预定样本且无评测错误。这不是 1,172 道互不相同的题：各模型使用相同任务序列进行对照，早期小样本也被直接复用。数学共 1,000 个实例，写作 82 个，代码 90 个。调试阶段的失败与重试记录保留在 Slurm 日志中。

Base 是未进行本轮微调的 Llama-3.1-8B-Instruct；Proactive Base 使用相同权重并加入论文的主动协作提示。SFT 是我们训练的监督微调模型；Offline DPO 从对应 SFT 权重出发，使用作者已发布的偏好数据继续训练。作者公开适配器单独加载评测。

下列单元格均为 **我们的测量值 / 论文 Table 1 报告值**；“—”表示没有对应测量或无法确认对应论文行。任务分数与 ITR 按百分数展示，token 数是每段完整对话中助手输出的平均千 token 数。写作 BLEU 保留原实现的字符级计算，不是词级 BLEU。

这些点估计表明：Offline DPO 的写作分数高于本轮 Base/SFT，数学只比 SFT 高 1 个百分点，代码与 SFT 同为 3/20。相对 Base，三个任务的助手输出均较短；相对 SFT，写作输出反而较长。任务分数上的部分接近不能解释为完整复现成功，尤其是 ITR 与论文仍有较大差距。

ITR 使用历史公式 `100 × 2 × (raw_score − 2.5)`，原始分数范围为 1–3，因此显示范围可达 −300% 到 100%。它不是成功概率，负值是合法结果；本文没有把负值截断或重新归一化。

数学的同题配对比较：Offline DPO 相对 Base 多答对 21 题、少答对 14 题，净增 7/200 = 3.5 个百分点，双侧精确 McNemar p=0.311；相对 SFT 多答对 19 题、少答对 17 题，净增 1 个百分点，p=0.868。本轮单次采样尚未建立统计显著的准确率提升，且这些探索性比较没有进行多重检验校正。

两者诊断都只采样 3 个未来分支、最多 4 条新消息、每条最多 256 个输出 token，并用 GPT-4o-mini 模拟与评分。Online DPO 使用现代 TRL 的初始策略冻结副本作为参考；PPO 使用关闭 LoRA 的基座参考。它们证明训练链路能更新参数，不证明收敛或论文级效果。没有完整在线训练的可靠成本测量，因此“未运行”是当时的预算分配取舍，不能写成“已证明 $40 一定无法完成”。

下列协议差异决定了本轮不能被称为严格同条件复现：

- 实验时原 Claude 3.5 Sonnet 两个快照返回 404，评委替换为 Claude Sonnet 4.5 `20250929`。
- 写作／代码的用户模拟使用 GPT-4o，数学使用 GPT-4o-mini，遵循归档脚本；论文正文对模拟模型的描述与脚本并不完全一致。
- 保留归档任务专属评委提示；其与论文 v3 附录单独的 ITR 提示有差异。评委替换和提示差异的影响没有单独做消融，不能将全部 ITR 差距归因于其中一项。
- 本轮使用 BF16，归档模型加载器使用 NF4。现代 TRL 的 DPO 截断处理也不同；实际 DPOConfig.max_length 取 max_new_tokens，即写作 2048、代码／数学 1536，使用 keep_end。args.json 中 max_seq_length=4096 是未接入 DPOConfig.max_length 的 CLI 字段，不能据此认定有效训练长度为 4096。
- 评测最终 3-epoch SFT／8-epoch DPO 检查点，未按验证集挑选最佳检查点。归档目录名不能充分证明论文实际选择的检查点。
- 初次完整 SFT 在初始化 LoRA 后才设置 Trainer 的种子，因此无法保证从头训练逐位复现；保存的对话、原始评委输出和模型权重均可追溯。
- 写作仅 18/100、代码仅 20/600（公开适配器为 10），数学为 200/200；每任务每模型仅一次对话采样，没有多随机种子重复。
- 公开适配器训练阶段不明；代码存在上述切分重叠；PPO／Online DPO 完整结果与 veRL 训练结果均缺失。
